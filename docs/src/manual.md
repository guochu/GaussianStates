# 理论与算法

本页给出 `entropy` 与 `osee` 的**定义**，以及包内协方差快速算法的完整理论，
包括 doubled 空间构造与复数输入下的共轭约定。所有公式都已用稠密构造
（直接在 Fock 空间建密度矩阵/态矢量）逐元素仲裁验证，误差 1e-10 ~ 1e-16
（见 `test/runtests.jl` 与 `GTEMPO/osee/osee_report.md`）。

## 1. 高斯态与 BdG 矩阵约定

### 费米

Nambu 自旋量 `ψ = (c₁..c_m, c†₁..c†_m)`，态

```text
ρ = exp(−½ ψ†·M·ψ) / Z ,     M 厄米
```

M 只有**两个独立块**：`(2,2)` 块由反对易关系 `c_i c†_j = δ_ij − c†_j c_i`
并入 `(1,1)` 块（差一常数），标准规范取

```text
M = ⎡ h   A ⎤ ,    h 厄米，A 反对称
    ⎣ A† −hᵀ⎦
```

用 [`fermionic_bdg_matrix(h, g)`](@ref) 组装（`A = g − gᵀ`，g 的对称部分
不影响态）。该规范满足**粒子–空穴对称**

```text
M·S₀ = −S₀·M̄ ,     S₀ = [[0, I], [I, 0]]
```

这是 OSEE 的 doubled 构造（§4.2）的前提。

**纯配对输入**：另一类合法输入是复反对称矩阵 `W`（2n×2n），描述纯态

```text
|Ψ⟩ = exp(½ c†·W·c†)|0⟩
```

这是影响泛函（IF）系数态的形式（`IF = exp(Σ Δ_pq ā_p a_q)` 的系数张量），
模式空间本身就是 doubled 的（a₁..aₙ, ā₁..āₙ）。

### 玻色

正则坐标序 `R = (x₁, p₁, x₂, p₂, …)`，`[x_a, p_b] = iδ_ab`，态

```text
ρ = exp(−½ Rᵀ·K·R) / Z ,     K 实对称正定
```

用 [`bosonic_bdg_matrix(h, g)`](@ref) 从**Bogoliubov 块**组装（`h` 复厄米、
`g` 复任意，只有 `g` 的对称部分有效）：

```text
H = Σ h a†a + ½(a† g a† + h.c.) = ½ Rᵀ K R + const
Kxx = Re(h) + Re(g_s) ,   Kpp = Re(h) − Re(g_s) ,
Kxp = 2 (Im(g_s) − Im(h))     （Im(h) 反对称 → 磁型反对称块）
```

**为什么 K 恒为实**：x,p 算符在 Fock 基下是实矩阵，H 的厄米共轭对应 K̄，
故厄米 H ⟺ K 实对称（K 的反对称部分只贡献常数）。这不是"玻色子不能有复
系数"——复的 h、g 完全合法（如复耦合、带相位压缩），只是 (x,p) 基把它们
归一为实 K，无信息损失。辛形式 `Ω = ⊕_k [[0,1],[−1,0]]`。

注意**真正复对称的 K**（非厄米算符，如复轮廓上的玻色影响泛函
`exp(−½RᵀKR)` 系数态）：其 OSEE 的**定义**仍然存在（向量化 + SVD 对任何
算符都可执行，奇异值恒实非负），失效的是本包的**协方差快速算法**——复 K
的 doubled 协方差 σ 是复对称的，辛本征值 Ωσ 复化，熵公式
`Σ[(ν+½)ln(ν+½) − (ν−½)ln(ν−½)]` 出现复数与分支切割，不再等于 SVD 熵。
稠密路线可行但指数代价；快速算法需要复辛结构的专门推导，故暂不接受该类输入。
这与费米侧形成对照：费米对**任意**向量 Majorana 协方差恒实（γ_aγ_b − δ 反厄米），
快速算法不依赖 ρ 的厄米性。

### 玻色纯配对（IF 系数态）

玻色影响泛函 `I[ā,a] = exp[Σ ā_p Δ_pq a_q]` 的系数态是 doubled 空间的
**纯高斯向量**，对应实对称、谱 ⊂ (−1,1) 的非正定配对矩阵：

```text
|Ψ⟩ = exp(½ c†·W·c†)|0⟩ ,    W = [[0, M], [Mᵀ, 0]] ,   M = exp(−Δ)
```

- ρ = |Ψ⟩⟨Ψ| **不是** Gibbs 形态：纯高斯向量的生成元必带相位/反对称部分，
  任何有限正定 K 都给不出纯态（thermal of PD-K 恒混合）——这就是"配对
  矩阵不满足 bdg 正定性要求"的理论根源，解法是独立的纯配对分支
  （`isbdg = false`，`entropy` 报错，`osee` 取 Γ 限制熵）。
- 取 `M = exp(−Δ)` 而非 `exp(+Δ)`：直接配对振幅奇异值 > 1 使
  `I − W²` 不定、公式数值失败；二者只差每模粒子–空穴反射，时间割
  Schmidt 谱相同（几何分布 `p_n ∝ t^{2n}` 在 `t ↔ 1/t` 下不变，熵不变）。
  仅支持**实 Δ**（虚时 Matsubara contour）。
- 协方差闭式（`W = QΛQᵀ`，谱上 `G_k = 1/(1−λ_k²)`、`K_k = λ_k/(1−λ_k²)`）：

```text
G = (I − W²)⁻¹ = ⟨cc†⟩ ,   K = G·W = ⟨cc⟩
σ_xx = G + K − ½I ,   σ_pp = G − K − ½I ,   σ_xp = 0
```

σ 正定、辛本征值全 ½（纯态）；等价于 ⊗ 双模压缩对（`tanh r_k` = W 的
分块奇异值）。理论来源：TEMPO/osee 报告 §5.2（d→∞ 高斯极限）。注意该值
由 Δ 的最小正实谱 λ_min 控制（`S ~ ln(1/λ_min)`），与固定 Fock 截断 d 的
TEMPO PT/ADT bond 熵是同一条曲线的两端。

## 2. 协方差矩阵

| 类型 | 协方差 | 基 | 对称性 |
|---|---|---|---|
| 费米 | `Γ_ab = i⟨γ_aγ_b⟩` | Majorana `γ_{2m−1} = c_m + c†_m`，`γ_{2m} = i(c†_m − c_m)` | 实反对称 |
| 玻色 | `σ_ab = ½⟨{R_a, R_b}⟩` | 正则坐标 | 实对称 |

**实数性保证**（与 bdg 是否复无关）：

- 费米：对任意态（含复 W 的纯配对向量），`γ_aγ_b − δ_ab` 是**反厄米**算符，
  期望值纯虚，故 `Γ_ab = i⟨γ_aγ_b⟩`（丢弃对角 δ）严格实；
  `⟨γ_aγ_b⟩ + ⟨γ_bγ_a⟩ = 2δ_ab` 保证严格反对称。数值实现再做取实与
  反对称化清理舍入。
- 玻色：Gibbs 分支要求 K 实对称 ⟹ ρ 实对称 ⟹ σ 实对称；纯配对分支要求
  W 实对称 ⟹ 系数向量可取实表示 ⟹ σ 实对称。

访问不经导出函数：任何熵计算后直接读字段 `s.Γ`（惰性计算并缓存；
初始为 `nothing`，首次需要时可用非导出的 `GaussianStates.covariance(s)`
触发计算）。

## 3. entropy：子系统（偏迹）熵

### 定义

对模式子集 A（物理模式指标），约化密度矩阵 `ρ_A = Tr_{Ā} ρ`，

```text
S(A) = −Tr ρ_A ln ρ_A          （α = 1，von Neumann）
S_α(A) = (1−α)⁻¹ ln Tr ρ_A^α    （Rényi）
```

这是**偏迹熵**，与 osee（§4）是不同的量：纯态上二者相等，混合态一般不等。

**定义域**：仅当输入是密度矩阵形态（字段 `isbdg = true`，即 ρ = exp(−½ψ†Mψ)/Z
且 M 厄米 / K 实对称正定）时有意义；否则（如费米纯配对算符
exp(½c†Wc†)，`isbdg = false`）ρ 不是密度矩阵，调用 `entropy` 直接报错——
其纠缠量请用 `osee`。构造时按输入对称性自动判定并赋值 `isbdg`。

### 快速算法

高斯态的约化态仍是高斯态，由 Γ 限制到 A 的行列指标完全决定：

- **费米**：`eigvals(iΓ_A) = ±ν_k`（|ν| ≤ 1），

  ```text
  S = Σ_k h((1+ν_k)/2) ,    h(p) = −p ln p − (1−p) ln(1−p)
  ```

- **玻色**：`eigvals(Ω_A σ_A) = ±iν_k`（ν ≥ ½），

  ```text
  S = Σ_k [(ν_k+½)ln(ν_k+½) − (ν_k−½)ln(ν_k−½)]
  ```

每割一次限制 + 本征值分解，O(模式数³)。Rényi 版本把每对 ±ν 视为两能级
`p± = (1∓ν)/2`（玻色为热模谱 `p_k = n̄^k/(1+n̄)^{k+1}`，有闭式）。

Γ 的构造：

- 费米 Gibbs：`⟨ψ_a†ψ_b⟩ = [Ū f(Λ) Uᵀ]_ab`，`f(λ) = 1/(1+e^λ)`，M = UΛU†。
  **注意共轭在行指标一侧**（`Σ_k conj(u_k)_a (u_k)_b f(λ_k)`）；实本征矢时
  退化为矩阵函数 f(M)。
- 费米纯配对：见 §4.3（Γd 即 Γ）。
- 玻色：令 `A = h^{1/2}`、`K = AΩA`（实反对称），则
  `Γ = A⁻¹ g(−iK/2) A⁻¹`，`g(z) = z·coth(z)`；校验 `h = ωI ⇒ Γ = ½coth(ω/2)·I`。

## 4. osee：operator-space 纠缠熵

### 4.1 定义

把密度矩阵（或系数态）向量化为 doubled (ket,bra) 空间的**纯态**

```text
|ρ⟩⟩ = (ρ ⊗ I)|I⟩ ,     |I⟩ = Σ_s |s⟩|s⟩ （无符号的玻色 EPR；费米见下）
```

对模式子集 A 的 OSEE 即 |ρ⟩⟩ 在 A 与补集之间的二分纠缠熵。

**定义域**：`osee` 的定义（向量化 + SVD）对**任何**形态的输入（`isbdg` 真假
均可、任何算符）都成立。本包的**快速算法**在费米侧对任何二次型指数算符可用
——对**任意**向量，γ_aγ_b − δ_ab 反厄米 ⟹ Majorana 协方差恒为实，机器不依赖
ρ 厄米；纯配对分支（exp(½c†Wc†)、Keldysh IF 的 exp(ΣΔāa) 等）正是靠这一性质。
玻色侧复对称 K 的 doubled 协方差是复的，快速算法失效（见 §1），因此该类输入
不被接受（玻色 `isbdg` 恒 true）。

**费米的 Z₂ 一致性**：费米约化采用协方差（Z₂ 超选一致）的定义——它与
Grassmann/IF 形式体系、以及 GTEMPO GrassmannMPS 的 bond 熵是**同一约定**。
注意它与 plain 张量 reshape 的 operator-Schmidt 在非连续割上不同
（JW 符号结构 (−1)^{|s|(|s|−1)/2} 造成的差异；等价于把割的 模式重排为
JW 串的连续前缀后再做 SVD）。

### 4.2 费米 Gibbs 分支的 doubled 构造

设 M 厄米且 PH 对称，本征分解 `M u_k = λ_k u_k` 取正半谱 λ_k > 0，
伴模（−λ 本征矢）为 `S₀·conj(u_k)`。Bogoliubov 模
`f_k = Σ_a conj(u_{a,k}) ψ_a`，`c_i = Σ_k V₊[i,k] f_k + V₋[i,k] f_k†`
（V = U 的 c-行块）。则

```text
|ρ⟩⟩ = Π_k (|00⟩ − t_k|11⟩)_{(f_k^A, f̄*_k^B)} · (Bogoliubov 旋转) ,  t_k = e^{−λ_k}
```

doubled 空间 [c^A(1..m); d^B(m+1..2m)] 的二点函数（**复数情形的三处
共轭位置**，均已对稠密 |ρ⟩⟩ 仲裁；实数时相关项退化为零/实形）：

```text
G_A = [Ū f₂(Λ) Uᵀ]_{cc} ,  F_A = [Ū f₂(Λ) Uᵀ]_{c†c} ,   f₂(λ) = 1/(1+e^{2λ})
      （A 拷贝 = ρ² 的关联）
G_B = conj(G_A) ,          F_B = −conj(F_A)             （B 拷贝为共轭表示）
F_AB = −(V₊ t̃ V₊† + V₋ t̃ V₋†) ,   t̃_k = 1/(2cosh λ_k)
G_AB = −conj(V₊ t̃ V₋ᵀ + V₋ t̃ V₊ᵀ)                       （复数时非零！）
```

经 `_majorana_covariance` 组装成 4m×4m 的 Γd（纯态：Γd² = −I）。
公式对简并本征空间的基选择规范不变（ε、t̃ 在简并块上为常数）。

**实现说明**：`⟨ψ_a†ψ_b⟩ = ŪfUᵀ`（而非 f(M) = UfU†）——实本征矢时二者
相同，这正是历史上实数测试全对而复数虚部反号的原因。`G_AB` 在实数时恒为
零，复数时必须保留。

### 4.3 费米纯配对分支

|Ψ⟩ = exp(½c†Wc†)|0⟩ 本身就是 doubled 空间的纯高斯态，Γd = Γ：

- 纯 ā–a 配对（W 只有 [ā, a] 块）：SVD 闭式。`W = U S V†`，配对占据
  `ε_k = s_k²/(1+s_k²)`：

  ```text
  ⟨c'†c'⟩ = V ε V† ,   ⟨c̄†c̄⟩ = Ū ε Uᵀ ,   ⟨c̄c'⟩ = −U s̃ V† ,   s̃ = s/(1+s²)
  ```

- 一般复反对称 W：湮灭条件 `α = c − Wc†`（BCH 精确终止）给出**混合共轭
  Stein 方程**

  ```text
  G + W̄ Ḡ Wᵀ = W̄ Wᵀ ,    F = W G − W        （注意是 Ḡ；W 奇异亦可用）
  ```

  解耦为 `K = W⊗W̄` 的 n²×n² 线性系统。

这一分支的 OSEE 与 GTEMPO GrassmannMPS 的 bond 熵逐割一致（机器精度，
见 `GTEMPO/osee/osee_gauss_joint.jl` 的四 contour 联合回归）。

### 4.4 玻色分支

Williamson 分解 `h = S⁻ᵀ diag(ω) S⁻¹`（实现：iAΩA 的 +ω 本征矢 w，
u = A⁻¹w，q = √2Re u、p = −√2 Im u，按 qᵀΩp = 1 归一化；该构造满足
hq = ωΩp、hp = −ωΩq，从而 SᵀhS = diag(ω,ω) 且 S 辛）。

由对称纯化形式 `|ρ⟩⟩ = (ρ^{1/2} ⊗ ρ^{1/2})|I⟩`：Williamson 基下 doubled
态 = ⊗_k 双模压缩对（tanh r_k = e^{−ω_k}），但 copy-B 是**转置表示**
（pᵀ = −p），对应 B 拷贝坐标的 p 反号 `Z = diag(1,−1,…)`：

```text
单侧块   X = S (⊕_k coth(ω_k)/2 · I₂) Sᵀ        （= ρ² 的协方差）
交叉块   = S (⊕_k csch(ω_k)/2 · I₂) Sᵀ · Z       （Williamson 基下全 + 对角）
B 同侧块 = Z · X · Z
```

结果为 doubled 空间的纯高斯态（辛本征值全 ½）。OSEE = Γd 限制子矩阵的
辛本征值熵，无 Fock 截断误差。

### 4.5 复杂度与调用约定

- 每割 O(模式数³)；Γd 惰性计算一次、缓存复用。
- `sites` 是 **doubled 空间模式指标**：Gibbs/玻色为 ket 拷贝 1..m 与
  bra 拷贝 m+1..2m，物理 site p 的割 = `[p, m+p]`；纯配对为 Grassmann
  模式本身（a₁..aₙ, ā₁..āₙ），site p 的割 = `[p, n+p]`。
- Gibbs 分支要求 PH 对称且谱无零模，否则调用报 `ArgumentError`
  （`entropy` 不受影响）。

## 5. 数值验证摘要

| 内容 | 方法 | 精度 |
|---|---|---|
| 费米 Gibbs Γ（实/复，含配对） | 与稠密 ρ 的 Majorana 协方差对照 | 1e-10 |
| 费米 Gibbs doubled Γd（实/复） | 纯度 Γd²=−I + 与高斯向量化 SVD 熵对照 | 1e-10 |
| 费米纯配对 Γ | 与 JW 稠密态对照 | 1e-10 |
| 玻色 Γ / Γd | 与 Fock 截断稠密 ρ 对照；辛本征值全 ½ | 1e-8（截断极限） |
| 纯配对 OSEE ≡ GMPS bond 熵 | GTEMPO 四 contour（虚时/实时/混合/BCS）联合回归 | 1e-14 ~ 1e-10 |
| 单模/直积极限 | 解析公式（费米 h(s²/(1+s²))、玻色热模熵） | 1e-12 |

`densitymatrix` 提供稠密参考（费米精确；玻色 Fock 截断），仅供调试——
`osee`/`entropy` 的实现完全不经过它。
